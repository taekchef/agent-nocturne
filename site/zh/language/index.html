灯效语言

一套简单的光线语法。

亮度保持全局统一，状态由节奏表达。

思考中 4.8 秒呼吸

Agent 正在推理。较长的吸气和更慢的呼气保持存在感，但不会持续打扰你。

优先级就是语法。

注意状态覆盖工作状态，工作状态覆盖思考状态。任务结束后，daemon 恢复用户原本的键盘亮度。

  1. 需要注意权限、等待输入
  2. 失败终局错误、工具错误
  3. 工作工具、压缩、后台任务
  4. 思考Thinking

完整状态词汇。

工作

thinking
4.8 秒非对称呼吸
tool
一次进入提示，随后保持 1.8 秒活动脉冲
compact
非常缓慢的低亮度呼吸
background
低亮度心跳

注意与结束

permission
高对比度闪烁
waiting-input
两次提醒轻触
tool-error
一次可恢复的柔和下沉
done
一次完成呼气
error
四段终局错误闪烁
idle
恢复用户最新亮度基线

让灯效开始工作。
