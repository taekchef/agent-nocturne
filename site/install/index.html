Install

One local core. Add the adapters you use.

macOS, Node.js 20 or newer, and a MacBook with a backlit keyboard.

Install the core

The daemon owns state, timing, and brightness restoration.

git clone https://github.com/taekchef/agent-nocturne.git
cd agent-nocturne
npm run build:native
npm link
nocturne config init
nocturne daemon start
nocturne status

Add an adapter

Each adapter observes lifecycle events only. It never changes prompts or permission decisions.

Pi

Link the extension, then run /reload inside Pi.

mkdir -p ~/.pi/agent/extensions
ln -sf "$PWD/adapters/pi/agent-light.ts" \
  ~/.pi/agent/extensions/agent-nocturne.ts

Claude Code

Install the official plugin from the repository marketplace.

claude plugin marketplace add taekchef/agent-nocturne
claude plugin install agent-nocturne@agent-nocturne

Codex CLI and Desktop

Install the plugin, then open /hooks and review its 11 definitions.

codex plugin marketplace add taekchef/agent-nocturne --ref main
codex plugin add agent-nocturne@agent-nocturne

Test, then restore.

Run a short breath and completion effect. Restore returns the captured keyboard brightness.

nocturne test thinking --duration 3
nocturne test done --duration 1
nocturne restore

Private by construction.

Runtime processing stays on the Mac. Hooks write no model-visible output. The Unix socket is user-only and adapters fail open if the core is unavailable.

The native helper dynamically uses Apple's private CoreBrightness framework. It needs no kernel extension or elevated privileges, but a future macOS release may change the API.

Remove it cleanly.

nocturne restore
nocturne daemon stop
claude plugin uninstall agent-nocturne@agent-nocturne
codex plugin remove agent-nocturne@agent-nocturne
npm unlink -g agent-nocturne

The compatibility command agent-light and existing AgentLight configuration remain valid during transition.
