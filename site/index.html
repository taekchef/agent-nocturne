Install

Install once. Add your agents.

macOS, Node.js 20 or newer, and a MacBook with a backlit keyboard.

Core
git clone https://github.com/taekchef/agent-nocturne.git
cd agent-nocturne
npm run build:native
npm link
nocturne config init
nocturne daemon start
nocturne status

Link the extension, then run /reload inside Pi.

mkdir -p ~/.pi/agent/extensions
ln -sf "$PWD/adapters/pi/agent-light.ts" \
  ~/.pi/agent/extensions/agent-nocturne.ts

Install the plugin from the repository marketplace.

claude plugin marketplace add taekchef/agent-nocturne
claude plugin install agent-nocturne@agent-nocturne

Install the plugin, then review its hook definitions in /hooks.

codex plugin marketplace add taekchef/agent-nocturne --ref main
codex plugin add agent-nocturne@agent-nocturne
