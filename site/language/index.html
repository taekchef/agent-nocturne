Lighting language

A small grammar of light.

Brightness stays global. Cadence carries the state.

Thinking 4.8 second breath

The agent is reasoning. The long inhale and slower exhale stay present without demanding attention.

Priority is the grammar.

Attention interrupts work. Work interrupts thought. A completed turn resolves the session and returns the user brightness.

  1. AttentionPermission, waiting input
  2. FailureTerminal error, tool error
  3. WorkTool, compact, background
  4. ThoughtThinking
